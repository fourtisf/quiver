Trust model

Don't trust us. We made sure you don't have to.

How it stays safe

  • Non-custodial. Positions are standard Uniswap NFTs in your wallet. Hoodpool never holds funds between transactions.
  • Immutable. No owner, no admin keys, no upgrade hooks on core contracts. The treasury is a multisig.
  • Factory-gated. A token lists only if its launch verifies on-chain. No one can list — or delist — by hand.
  • Manipulation-resistant. TP/SL executes on a time-weighted price with slippage bounds you set. Revoke the approval, and the order dies with it.
